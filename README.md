# Starbucks Beverage Analysis – Power BI

An interactive Power BI dashboard for analyzing Starbucks beverage products based on nutritional information, caffeine levels, calories, sugar content, beverage categories, and preparation methods.

## 📌 Project Overview

This project uses Power BI to explore and visualize nutritional and beverage-level information from Starbucks products.

The dashboard provides an interactive view of beverage categories, calories, sugar, caffeine, and other nutritional attributes. Users can apply filters to explore the data based on protein range and beverage preparation methods.

The project was created as a guided Power BI project to strengthen skills in data cleaning, data modeling, DAX, visualization, and dashboard design.

## 🎯 Objectives

* Analyze Starbucks beverages across different categories.
* Compare average calories and caffeine levels between categories.
* Identify beverages with high caffeine content.
* Understand the distribution of beverages across categories.
* Explore nutritional characteristics such as sugar, protein, and calories.
* Build an interactive and visually appealing Power BI dashboard.

## 📂 Dataset

The dataset contains nutritional information for Starbucks beverages.

### Dataset Details

* **Records:** 242
* **Beverage Categories:** 9
* **Beverages:** 33
* **Beverage Preparation Methods:** 13
* **Nutritional Attributes:** Calories, Fat, Sodium, Carbohydrates, Cholesterol, Sugar, Protein, Vitamins, Calcium, Iron, and Caffeine.

## 📈 Dashboard Features

### KPI Cards

The dashboard includes key metrics such as:

* Total Beverages
* Average Sugar
* Average Calories
* Average Caffeine

### Visualizations

* Average Calories by Beverage Category
* Starbucks Global Presence Map
* Beverage Category Distribution
* Average Caffeine by Category
* Top 5 Highest Caffeine Beverages

### Interactive Filters

* Protein Range
* Beverage Preparation

These filters allow users to interactively explore the beverage data.

## 🔍 Key Insights

* Smoothies have the highest average calorie level among the beverage categories, followed by Frappuccino® Blended Coffee.
* Coffee has the highest average caffeine level among the categories in the dataset.
* Brewed Coffee has the highest average caffeine content among individual beverages.
* Classic Espresso Drinks represent the largest category in the dataset, with 58 records.
* Tazo® Tea Drinks are the second-largest category with 52 records.
* Frappuccino® Blended Coffee contains 36 records in the dataset.
* Beverage categories show significant differences in their average calorie and caffeine levels.
